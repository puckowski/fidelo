Fidelo is a two-stage PyTorch system: a residual vector-quantized audio autoencoder learns discrete sound tokens, then a text-conditioned GRU learns to arrange those tokens into music.

01 / TRAINING

Two stages.
One token language.

Stage A teaches the tokenizer to preserve waveform and spectral detail. Stage B freezes that tokenizer, converts dataset audio into code IDs, and trains the prior with teacher forcing to predict the next code.

train_latent_audio_tokenizer.py → train_latent_audio_prior.py
Encoder

32× temporal compression

Three strided convolution stages reduce the waveform timeline while channels grow to 512, followed by a 384-channel latent bottleneck.

Quantizer

Residual code streams

Each quantizer selects its nearest learned 384d vector. With multiple quantizers, each stage encodes the previous stage’s remaining residual.

Optimizer

Stable mixed precision

CUDA autocast reduces eligible operation precision; gradient scaling, unscale-before-clipping, and AdamW keep updates stable.

BOS controls

Two input-only starts

Audio IDs 0–2047 can be predicted and decoded. Regular BOS 2048 and song-beginning BOS 2049 only seed the prior; neither can appear in generated audio codes.

02 / INFERENCE

Prompt to waveform.

Inference is autoregressive and runs in evaluation mode without gradients. Optional retrieval guidance compares model proposals with prompt-matched dataset code windows before the frozen decoder reconstructs audio.

generate_latent_audio_cuda.py · no_grad · CUDA by default
Context

BOS once, text throughout

The selected BOS seeds an unprefixed clip, then real audio IDs take over. The pooled 256d prompt remains concatenated with each 384d code embedding throughout generation.

Sampling

Controlled stochasticity

Temperature, top-k, nucleus filtering, and recent-token penalties balance variation against coherence without changing model weights.

Guidance

Retrieval, not attention

Optional guidance substitutes real code windows outside the GRU. Structured inference keeps song-beginning sources in intro sections; this is separate from the BOS clip-count flag.

03 / NUMERICS

Precision
with purpose.

The code uses automatic mixed precision for both training scripts on CUDA, while ordinary inference does not enter an autocast region.

FP32

Input waveforms, stored parameters, optimizer state, validation, checkpoint serialization, and the default inference path use standard single precision.

FP16 / AMP

Inside CUDA training autocast, eligible convolution, matrix, GRU, and linear operations may execute in lower precision. PyTorch retains higher precision where required.

GradScaler

Scaled loss protects small FP16 gradients. Gradients are unscaled before the global norm is clipped to 1.0, then AdamW performs the update.

INT64 IDs

Text IDs, BOS, and latent code indices remain integer tensors. Audio IDs 0–2047 map to codebook vectors; BOS IDs 2048 and 2049 exist only in prior input embeddings.
